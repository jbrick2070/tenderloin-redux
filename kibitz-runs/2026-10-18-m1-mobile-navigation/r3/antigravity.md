4. [Section 2 (`public/world.js`) / Section 3 (`resize`)] `ResizeObserver` in `World` clears the canvas bitmap after `requestAnimationFrame` without redrawing. In `public/world.js:23, 48, 50-57`, `this.measure()` runs both synchronously in `constructor` and asynchronously via `ResizeObserver`. `measure()` unconditionally assigns `this.canvas.width = Math.round(rect.width * ratio); this.canvas.height = Math.round(rect.height * ratio);` (`public/world.js:53`) and does not call `this.draw(...)`. Per the HTML Canvas specification, setting `canvas.width`/`height` (even to the same value) resets the canvas bitmap to transparent black, and `ResizeObserver` callbacks run after `requestAnimationFrame` callbacks and immediately before paint, wiping the rendered frame on initial observation and during window resizes.
   Concrete fix: In `public/world.js:53`, only assign `this.canvas.width` and `this.canvas.height` when the rounded pixel dimensions differ from current `this.canvas.width`/`this.canvas.height`, and call `this.draw(this.time, false)` (or redraw if initialized) when `measure()` resets the canvas buffer.
