# TenderVoice reuse research

Checked 2026-10-18 (America/Los_Angeles).

## Decision

Open-source status is UNVERIFIED. No source or media has been imported. The creator authorized reuse if it is open source; that condition has not been established. This is not proof that source does not exist.

The constructive next design step is an original Neighborhood Voices feature in CONCEPT.md, with a direct-access map/directory and optional voice-to-organization matching. Keep the earlier project's historical credit, without claiming a partnership or copying its expression.

## Evidence

1. St. Anthony Foundation's historical description confirms a Tenderloin Tech Lab/Arup web application with organizations and audio about their missions and services. The page does not provide a software license or source repository.
   https://www.stanthonysf.org/tendervoice-in-the-tenderloin/
2. Central City Extra, June 2010, page 5, describes matching short voice clips to accurately mapped organizations, plus longer interviews. The PDF's upload-path date is not the publication date. The newspaper is evidence of behavior, not a license to reuse the application or recordings.
   https://studycenter.org/wp-content/uploads/2019/03/ccx.101-cALL-copy.pdf
3. Contributor Shane Myrbeck's portfolio identifies the project and links to its former site and paper. No source license was identified on that portfolio page; following the former application and paper links failed in this research session.
   https://shanemyrbeck.com/portfolio/tendervoicetendernoise/
4. Yellowskyscraper's indexed portfolio lists TenderVoice and TenderNoise in June 2010. Direct opening was unreliable; use this as a lead, not licensing evidence.
   https://yellowskyscraper.com/work
5. GitHub REST repository searches: `tendervoice` -> 0 results; `TenderVoice in:readme` -> 0 results. `tendernoise` -> one result, Hankago/tendernoise, with description `semplice` and no detected license. No relationship to the historic project was established; it is not a usable dependency.
   Search endpoint: https://api.github.com/search/repositories
6. Web searches for TenderVoice with GitHub, open source, license, Creative Commons, and source-code terms found historical descriptions but no suitable source-and-license pair in this session.
7. The authors' paper, TenderVoice / TenderNoise, describes making the interface open source as a future possibility ("can be made open source"). That is not evidence that a release or license followed. Its acknowledgments credit Jim Hovell of Yellowskyscraper for the TenderVoice website. Full PDF opening timed out, but the search index exposed the relevant passage; retain that access limit.
   https://citeseerx.ist.psu.edu/document?doi=3ac68dc203a47c1d0df34830c1d27189a79f0cc1&repid=rep1&type=pdf
8. Gray Area's archived festival review confirms both the game format and direct access to community information without playing. It does not establish source or media permissions.
   https://grayarea.org/press/culture-debates-review-of-city-centered/

## Conditions for actual reuse

- Identify an authentic repository or source archive and its version/commit.
- Read the actual license and preserve applicable notices; assess compatibility and maintenance/security before dependency use.
- Establish separate permissions for historical interviews, photographs, artwork, organization logos, and any other media. A code license alone does not establish those rights.
- Document whether modernization is useful compared with an original implementation.

No outreach was sent. Potential leads are St. Anthony's/Tenderloin Tech Lab, the credited project contributors, and Arup. If later authorized, ask for source location, license, media permissions, and attribution preferences.

GitHub's licensing guidance distinguishes public visibility from permission to reproduce or distribute software: https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository
