## 3. Experimental-module recommendations

Accepted: one default-off setting, lazy loading, host-owned resources, separate optional audio from main jazz, core-owned checkpoints, no effect on completion, and off/on/off verification. No source-rights exception is introduced by disabling the module.

Refinements needed before implementation:

1. A core import ban needs a clear bootstrap exception: register the lazy loader outside core gameplay. Otherwise a literal universal import ban contradicts loading the module at all. These boundaries describe intended architecture, not a security sandbox.
2. Abort alone does not prevent late dynamic-import results or callbacks attaching after disable/re-enable. Use activation-generation checks and host-managed registrations; a thrown disposer must not stop the rest of cleanup.
3. The core save manager necessarily reads the envelope. It may retain bounded optional JSON as unknown data without interpreting its internal schema or importing module code. Do not demand truly unparsed data or byte-identical JSON while also parsing and rewriting the envelope. Preserve semantic content and core progress.
4. Unknown/corrupt optional state must be separated from corruption of the whole save file. Reset only the affected optional slice when appropriate. Loading saved optional data does not turn its setting on.
5. Core-state parity is meaningful only for the same seed, layout choices, and core actions. Exclude timestamps and optional state. Different intentional layout decisions should produce different outcomes.
6. The first experiment has no audio. Keep any synthetic teardown-tone fixture development-only. The suggested 100-ms silence target is a proposed foreground test threshold, not measured implementation or a universal browser latency promise. Verify main-music continuity, listener/resource cleanup, and stale-load behavior as well.
7. Asset inventory checks should cover shipped third-party/original media and dependencies, not fail because source documentation or review artifacts lack media rows. An inventory plus a license string is still not proof of valid reuse rights.

The review's 13 checks are useful future acceptance cases; none has been executed against a game because no application exists. Lint, bundling, browser support, audio timing, FPS, save migration, keyboard operation, and actual player enjoyment remain untested.
